Contributions to the Typst project

#7423: Improve the font features interface

My first PR to typst/typst; niche spec compliance stuff I was nerd-sniped into by a user doing work with Znamenny Notation, which has a pretty cool font that exposed a missing knob in Typst. More interesting (to me) than changing the type of a property however was discovering that pretty much no validation was done on raw OpenType features; I had a ton of fun remedying that handling all the weirdness of Unicode and OT while trying to report as nice errors as possible to end-users c:

I learned a lot about Typst, notably the diagnostics model and how elements are build. Beyond that, it was good practice of test coverage, correctness, and communication! This was the first time I had to pass a professional code review, which was a pretty interesting experience by itself; I'm very thankful to Laurenz for his patience and guidance with stylistic and technical considerations.

#7528: Friendly hint and docs clarification for array.sorted

This one was quite silly: mere hours before the 0.14.1 release, a PR was crated and merged that changed the sorting algorithm to a more resilient one. The change was good on a technical level, but had the unfortunate side-effect of exposing some previously invisible issues in user code as a hard error. I noticed after upgrading and trying to compile my diary, which happened to be affected; despite the error pointing right to the bad line, it was still a quite pain to figure out why I was suddenly seeing bad values (spoiler: they were always there). Later it turned out other users also experienced this issue, most notably through the glossy package.

The PR isn't very interesting on a technical level, but triaging and figuring out how best to handle this new situation was an intense experience. I'm quite happy with the result, and since had positive experiences in the support channels helping newer users resolve the hint they were now seeing. More recently, Laurenz talked talked about this (among other considerations) in defining and improving the long-term stability of Typst and its ecosystem on his blog: https://laurmaedje.github.io/posts/evolving-typst
